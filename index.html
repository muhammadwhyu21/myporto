Project 1 image

Window Cleaning Robot

A window cleaning robot that sticks to glass with vacuum suction and uses Coverage Path Planning to clean an entire surface automatically.

IoTRoboticsFinal College Project
Detail

or my final year project, I wanted to solve a problem that is easy to overlook: cleaning windows on tall buildings is risky for the people who do it. So I built a robot that does the job for them. It sticks to the glass using vacuum suction and drives with a differential drive system on sponge crawler wheels, so it doesn’t slip. To make sure no part of the window gets missed, I used a grid-based Coverage Path Planning algorithm with a boustrophedon (zig-zag) pattern. Time-of-Flight (ToF) sensors help the robot sense the edges of the window and decide when to turn, an MPU6050 keeps track of its orientation, and wheel encoders measure how far it has moved. Everything is controlled by an Arduino Mega. I calibrated and tested each sensor and the suction mechanism again and again, and that process taught me how much patience real hardware needs.
